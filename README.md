# GM Manager

App per il Master di giochi di ruolo di quinta edizione (regole 2014): mappa con nebbia e viaggi, tracker
dell'iniziativa, schede dei personaggi, dadi 3D, proiezione sul TV o sul proiettore, compendio della campagna e
assistente IA. Gira sul PC del Master; i giocatori entrano dal browser.

**Stato:** in preparazione (fase 3 del piano). Repository privato.

- Contenuti e licenze: `docs/LICENZE_E_CONTENUTI.md`
- Stato del lavoro: `STATO_LAVORO.md`
